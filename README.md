# 業務フロー帳

業務の手順を、担当ごとのレーンに分けたフロー図（スイムレーン図）で記録するツールです。
インストールは要らず、HTML ファイルをブラウザで開けば動きます。インターネットにつながっていなくても使えます。

## 主な機能

- 図の上でステップを足し、矢印でつなぎ、ドラッグで動かしてフローを描く
- 間にステップを入れると右側を自動でずらし、つなぎ直しても配置を崩さない
- ステップと帳票・データを関連（点線）で結ぶ
- 行き止まりや、開始からたどり着けないステップを知らせる
- 今の業務（AsIs）と見直した業務（ToBe）を比べ、違いを図に色で示す
- フローを YAML ファイルで保存する（共有フォルダや Git でも管理できる）
- PNG 画像（PowerPoint に貼る大きさ）、手順書（.md）、Mermaid 記法に書き出す

## はじめ方

1. `app` フォルダを、フォルダごと置きます。HTML ファイルだけを取り出すと動きません。
2. `app/業務フロー帳.html` をブラウザで開きます。
3. 「作業フォルダを選ぶ」で、フローを保存するフォルダを選びます。
4. 左の「ひな形から作成」か「＋ 新規」でフローを作ります。

`samples/` に、読み込んで試せる YAML があります。

## 保存のしかた

フローの中身はブラウザ内に保存しません。端末やブラウザのデータから業務フローが漏れないようにするためです。

| ブラウザ | 保存のしかた |
| --- | --- |
| Chrome・Edge | 選んだ作業フォルダに、1 フローずつ YAML ファイルとして自動で保存します。 |
| それ以外（Firefox・Safari など） | 開いている間だけ保持します。「エクスポート」（`Ctrl+S`）で YAML ファイルに保存し、次回は「インポート」で開いてください。 |

## セキュリティ

- サーバーはなく、ブラウザの中だけで動きます。アカウントや利用状況の収集もありません。
- フローの中身を外部へ送ることはありません。外部から読み込むのは画面のフォント（Google Fonts）だけで、その際に端末の IP アドレスやブラウザの情報などが Google に送られます。つながっていないときは、端末にあるフォントで表示します。
- 外部の部品は js-yaml だけで、同梱しています。

データを置く場所、通信を止める方法など、導入を判断するための情報は [SECURITY.md](SECURITY.md) にまとめています。
